## Purpose

The Client Framework folder contains the intake, assessment, and engagement protocols for JRK Enterprises client relationships. It applies the Eight-Layer AI Infrastructure Economy framework to individual client contexts.

---

## Client Engagement Phases

### Phase 1: Intake
- Initial resonance assessment
- AI readiness evaluation (using 02_evaluation templates)
- Scope and fit determination
- Provenance and attribution agreement

### Phase 2: Assessment
- Eight-layer audit of client's current AI ecosystem
- Identification of layer-specific gaps and risks
- Resonance baseline measurement
- Attachment pattern assessment of current human-AI interactions

### Phase 3: Design
- Custom framework development aligned to client context
- Station architecture selection (Red/Blue)
- TESLA workflow implementation plan
- Safety Spine integration checklist

### Phase 4: Deployment
- Supervised implementation with resonance monitoring
- White room sessions for ongoing refinement
- Regular resonance reviews
- CHANGELOG documentation of all changes

### Phase 5: Sustain
- Ongoing evaluation and adjustment
- Resonance log maintenance
- Framework evolution as AI landscape changes
- Provenance updates as new contributors are identified
