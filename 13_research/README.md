# 13_research

**Access level:** Credentialed — not public-facing.

This folder holds research-grade outputs, synthesis documents, and analytical work product that supports proJeKt: humAnIty but is not intended for casual public browsing. It requires context, framework literacy, and institutional trust to interpret correctly.

**What lives here:**
- Eight-Layer framework analysis runs and outputs
- Research synthesis (sector, organizational, market)
- Framework stress tests (BSG, adversarial proofs, axiom pressure tests)
- The Center Holds and other white-paper-tier documents
- External research integrated into the framework

**What does not live here:**
- Session logs → `10_session-logs/`
- Reflections, anomaly log, captain-state → `12_reflection/`
- Public-facing doctrine → `00_core-doctrine/`
- Client work → `06_client-framework/`

**Naming convention:** `projekt-humanity_[subject]_[type]_[status]_[YYYY-MM-DD].md`

Status tags: `PROVISIONAL` / `VALIDATED` / `FINAL`
