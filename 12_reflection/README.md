# 12_reflection

**Purpose:** Session reflections, captain-state notes, pattern observations, voice drift logs, and the proJeKt: humAnIty anomaly log.

**What lives here:**
- Anomaly log (CLEAN / SHAPED / UNCERTAIN entries)
- Captain-state observations (pace, fuse status, signal quality)
- Voice drift flags (when volume replaces precision, carrier-vs-source observations)
- Pattern logs (recurring behaviors, emergent structures, system self-observation)
- Post-session reflections

**What does not live here:**
- Raw session transcripts → `10_session-logs/`
- Structured analysis outputs → `11_analysis/`
- Doctrine → `00_core-doctrine/`

**Naming convention:** `projekt-humanity_[subject]_[type]_[YYYY-MM-DD].md`

**Anomaly log tags (mandatory on every entry):**
- `CLEAN` — observed, author did not intervene
- `SHAPED` — author made a choice that changed the outcome
- `UNCERTAIN` — author cannot determine if their presence changed the outcome
