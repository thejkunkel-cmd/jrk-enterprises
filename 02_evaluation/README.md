## Evaluation Philosophy

The JRK Enterprises evaluation framework is grounded in three commitments:

1. **Independence**: We evaluate AI systems without financial relationship to the vendors being evaluated
2. **Human Outcome Focus**: Technical performance is never the primary metric; human and institutional outcomes are
3. **Transparency**: Evaluation methodology and criteria are published and challengeable

---

## Scoring Framework Overview

Each AI system is evaluated across all eight layers using a 1–5 scale:

| Layer | Weight | Rationale |
|-------|--------|-----------|
| Layer 1: Infrastructure | 10% | Foundation reliability |
| Layer 2: Model Selection | 15% | Capability and bias baseline |
| Layer 3: Orchestration | 15% | Agentic safety and transparency |
| Layer 4: Data | 10% | Provenance and consent |
| Layer 5: Application | 10% | User experience and disclosure |
| Layer 6: Evaluation | 10% | Self-assessment and auditability |
| Layer 7: Attachment | 15% | Secure attachment design |
| Layer 8: Humanity | 15% | Human flourishing contribution |
