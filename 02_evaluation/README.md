# 02_evaluation

**What this is:** Scored evaluations of AI systems and companies against the eight-layer framework.

**Primary evaluation:** Microsoft vs. Perplexity — scored across all eight layers using publicly sourced and credited evidence.

**Methodology:** Each evaluation scores a subject against every layer of the framework, identifies where value is created or extracted, and flags governance gaps. All sources are cited per the Provenance Format standard.

**Status:** Evaluations in this folder are working documents. They are promoted to the research repository when validated.
