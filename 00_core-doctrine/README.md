## The Doctrine Stack

Doctrines are ordered from most fundamental to most applied. Nothing in any layer can override a layer above it.

| Doctrine | Function | Status |
|----------|----------|--------|
| **Floor Doctrine** | Non-negotiable ethical floor. Overrides everything. | ACTIVE |
| **Attachment Doctrine** | Governs how human-AI bonds form and must be protected | ACTIVE |
| **Wall Doctrine** | Identity and scope — what each thing is and is not | PROVISIONAL |
| **Window Doctrine** | Visibility and consent — what can be seen and by whom | PROVISIONAL |
| **Bridge Doctrine** | Authorized connection — how translation across entities works | ACTIVE |
| **Resonance Function** | Quality filter for all human-AI interaction | ACTIVE |
| **Safety Spine** | Cross-cutting guardrails referenced by all doctrines | ACTIVE |

Full doctrine files: [projekt-humanity-research](https://github.com/thejkunkel-cmd/projekt-humanity-research/blob/main/DOCTRINE-INDEX.md)
