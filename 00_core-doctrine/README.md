## Inheritance Rules

- All project rooms, workers, and lanes inherit the full doctrine stack
- No worker may author, extend, or overrule doctrine
- Conflicts between local instructions and this stack must be logged upward to MASTER
- The Safety Spine and Floor Doctrine are non-negotiable — no exception process exists for them

---

## How to Read This Folder

Start with `DOCTRINE-INDEX.md` for orientation. Then read `floor-doctrine.md` and `safety-spine.md` — those two documents define what cannot move. Everything else builds from there.

Do not treat any document here as a template or starting point for new work. These documents are stable references, not drafts.
