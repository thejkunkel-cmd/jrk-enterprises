## Naming Convention

All session logs follow this format:

`YYYY-MM-DD_[channel-or-topic]-[pass-or-descriptor].md`

Examples:
- `2026-06-07_echo-audit.md`
- `2026-06-09_repo-migration-pass1.md`
- `2026-06-10_red-outreach-sprint.md`

One file per session or pass. Do not append to existing logs — create a new file.
