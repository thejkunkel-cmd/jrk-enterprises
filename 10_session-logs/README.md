# 10_session-logs

**What this is:** Working session records — the raw operational log of project sessions.

**Function:** Documents what happened in each working session: decisions made, artifacts created, questions opened, and next steps. This is the project’s memory layer at the operational level.

**What belongs here:** Session summaries, decision logs, artifact creation records, and open questions from each session. Raw enough to be useful later, structured enough to be readable.

**Promotion rule:** Decisions logged here that affect doctrine, architecture, or research direction must be flagged and reviewed in MASTER before being treated as final.
