# 05_outreach

**What this is:** The VELA channel — active outreach operations.

**Function:** Control Room layer. This is where active relationship-building happens: direct messages, pitch sequences, proposals, partnership conversations, and CRM tracking.

**Posture:** Operational. Concrete. One action per move. VELA does not theorize — it executes against plans set in the White Room and scoped in `04_station-architecture/`.

**What belongs here:** Outreach templates, pitch sequences, contact lists, CRM exports, active proposal drafts.

**Guardrail:** Outreach content must pass the White Spine checklist before going out. Voice drift — where the outreach starts sounding like doctrine or starts overpromising — is an active risk and is tracked in the anomaly log.
